## About Me

Computer Science sophomore at Meredith College, building full-stack web apps and cloud-based tools — from a budgeting app deployed on Azure to a serverless reminder system on AWS.

- **Currently building:** cloud-based tools on AWS & Azure
- **Ask me about:** Python, Flask, REST APIs, or serverless architecture
- **Background:** Software Engineering Fellow at AmaliTech (Accra, Ghana, Summer 2025)

## Featured Projects

**[Pocket Buddy](https://pocketbuddy-eliza-guh4cydjd2bjbbcg.canadacentral-01.azurewebsites.net/)**
Full-stack budgeting app built with Flask and PostgreSQL, deployed on Microsoft Azure — helps students manage money independently for the first time.

**[Deadline Reminder](https://github.com/efr-maa/deadline-reminder)**
Serverless app for tracking classwork, work shifts, and commitments, with automatic email reminders. Built with AWS Lambda, API Gateway, DynamoDB, EventBridge, and SES.

**[Meredith Share Closet](https://efr-maa.github.io/Meredith-Share-Closet/)**
Multi-page responsive website supporting item sharing and donations within the Meredith College community.
